# Nixie Clock — ESP32 + ИН-12

Часы на газоразрядных индикаторах ИН-12 с управлением на ESP32,
синхронизацией времени по NTP/DS3231 и настройкой по BLE.

## Быстрый старт

```bash
# Сборка и заливка
pio run --target upload

# Монитор порта
pio device monitor
```

## Возможности

- Отображение времени на 4 или 6 лампах ИН-12 (настраивается)
- Синхронизация через NTP (SNTP) с сохранением на RTC DS3231
- Автономная работа от RTC (часы точные даже без WiFi)
- Настройка WiFi, часового пояса, формата времени через BLE
- 12/24-часовой формат (переключается без перезагрузки)
